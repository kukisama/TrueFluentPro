# 译见 Pro v2.2.3

## 更新内容

### 输入法安装、修复与卸载自动化
- **授权后自动继续**：权限不足时先提示，再由 Windows 请求管理员授权，并自动继续本次安装、修复或卸载；无需提前手动以管理员身份运行程序
- **保留主窗口与当前任务**：仅提升专用维护进程，主界面不退出；取消授权不修改安装，也不会循环弹出授权请求
- **维护前自动切换**：自动暂停听写、停止输入法后台，并在移除系统组件前切离译见输入法，不需要手工切换，不强制关闭其他应用
- **同版立即重装**：旧目录仍在系统回收队列时，自动选择新的安装目录，避免复用将被删除的路径，无需为了重装先重启 Windows

### 旧组件清理与状态显示修复
- **优先自动清理**：对短暂文件占用进行有限重试；已排队的旧 DLL 释放后也会再次尝试删除，不再直接跳过
- **明确区分卸载与缓存回收**：系统输入法入口已移除时明确显示卸载结果；仍被其他应用持有的旧文件由 Windows 在日常重启时回收，不再要求专门重启后再次点击确认
- **修复安装清单冲突**：后台热更新不再绕过安装流程改写 Host 身份，解决“原 Host 与本模块恢复清单不一致”导致安装、修复或卸载被拒绝的问题
- **刷新状态不再重启后台**：查询安装状态不再复制组件、结束或启动后台，避免卸载后刷新又拉起输入法宿主

### 版本一致性
- 主程序与双架构输入法组件统一为 **v2.2.3**，安装前核对组件版本一致
- 已安装组件版本读取实际文件，不再用历史清单中的 `1.0.0.0` 或当前主程序版本冒充；旧包缺少版本信息时明确显示未知
- 原生构建缓存纳入产品版本号，避免版本升级后仍沿用旧组件

---

### 运行前提

本版本为 **FDD（Framework-dependent）** 发布，需要预先安装： [**.NET 10 Desktop Runtime**](https://dotnet.microsoft.com/download/dotnet/10.0)

### 使用方式

1. 下载对应架构的 zip 文件
2. 解压到任意目录
3. 运行 `TrueFluentPro.exe`
