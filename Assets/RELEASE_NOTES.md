# 译见 Pro v2.2.2

## 更新内容

### 新增 Windows 原生语音输入法（译见pro输入法）
- **原生 TSF 输入法与常驻三格浮窗**：支持 Windows `x64` / `x86` 双架构应用无缝输入；选中译见输入法时在屏幕右下角常驻紧凑三格浮窗（`[译] | 🎤 | ⚙️`），支持拖拽位置并跨会话记忆，切换到搜狗等其他输入法或进入远程桌面/任务管理器时自动隐藏让出焦点
- **按键与鼠标双触发实时上屏**：按下 `F8` 或点击浮窗麦克风图标即可开始/停止语音听写，识别文字通过 Windows TSF 组合区实时上屏，不占用剪贴板
- **内存常驻配置与连接预热双路由**：独立宿主后台常驻缓存配置并自动热重载；默认开启连接预热（切换到输入法时后台零音频流预建识别连接，加速首次按 `F8` 出字），也可在设置中随时关闭恢复按需建连
- **独立设置弹窗与主程序互通**：点击浮窗右侧齿轮图标即可弹出独立“译见pro输入法设置”窗口，直接配置连接预热开关、语音资源、模型覆盖、麦克风设备、识别语言与句尾静音时长，并提供快捷入口打开主程序管理终结点与 AAD 登录

### 支持任意音频格式自动转换（听析中心）
- **非支持格式自动检测与弹窗确认**：从文件加载或拖拽导入音频时，自动检测是否为微软语音转录直接支持的格式；遇到 `.m4a`、`.mp4` 等不直接支持的容器格式时，先弹窗提示并展示转换信息，确认后自动开始转码
- **内置转码无需外部依赖**：直接复用程序内置的 Windows Media Foundation / NAudio / LAME 音频编码管线完成格式转换，无需额外安装或引入 `ffmpeg`
- **转换码流不超过原始码流**：自动探测原始音频码率，转换后的 MP3 码率严格限制为不超过原始音频码流（例如原始为 128 kbps，转换后最高不超过 128 kbps），避免无意义的体积膨胀
- **自动命名与无缝提交转录**：转换后文件自动添加 `-convert.mp3` 后缀（如 `xxx-convert.mp3`），完成后自动加入听析中心音频列表并直接提交转录及后续 AI 分析任务

### 音频源体验优化（音频设备弹窗）
- 新增**识别音源**与**录制来源**两组分段控件，支持一键三态切换：仅环回 🔊 / 环回+麦 🔊🎤 / 仅麦克风 🎤
- 默认两路均为「环回 + 麦克风」，开箱即用
- 切换时高亮指示器**平滑滑动**到目标格，配合主题感知配色（明/暗自动适配）和悬停反馈，更现代直观
- 单通道模式下不再采集闲置通道，减少 CPU 与磁盘占用

### 录音质量提升
- 新增**录音跟随 VAD 选源**模式（默认开启）：双声道场景下，录音只保留当前活跃说话方，避免麦克风背景噪音持续混入系统声音轨
- 设置 → 识别中可关闭，恢复传统的双轨混合录音
- 录音文件电平不再受识别端自动增益影响，原始动态范围更准确

### 时间轴显示修复
- 修复仅采集单通道时蓝/红时间轴条空白的问题，现在能正确反映实际启用的音源
