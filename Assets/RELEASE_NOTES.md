# 译见 Pro v2.3.0

## 更新内容

### 输入法工具统一工作区
- **一个窗口，三个分类**：用量、语言与翻译、设置合并到同一个工具窗，左侧固定分类导航；从浮条打开不同功能时复用已有窗口，减少反复开关
- **切换保留当前状态**：页面按需加载并保留，返回用量时不丢失已选会话与原文，快速切换不会停在过期页面
- **统一蓝白界面**：深蓝一体标题栏、白色圆角卡片和清晰的选中状态；支持最小化、最大化、还原、关闭及窗口大小调整

### 用量报表更易查看
- **顶部切换统计视图**：概览、每日趋势、小时分布、统计分布、会话记录分别显示，不再堆成需要反复下拉的长报表
- **共用日期范围**：今日、7 天、30 天与刷新固定在右上方，切换视图沿用同一统计快照，避免重复读取
- **会话记录整宽阅读**：会话列表独占右侧工作区，点击自动展开已保存原文，切换会话只保留当前详情；长段落自然换行、可滚动阅读和选择复制，不再与图表挤在窄栏
- **紧凑原文详情**：刷新改为标题右侧图标，正常阅读不再显示多余说明、批次状态或收起按钮；短句按内容收缩，分页、取消及必要提示仍保留

### 设置与语言操作简化
- **设置分成三个 Sheet**：识别、断句、输入法管理固定在顶部；识别页将资源与模型、麦克风与连接预热分成左右两张卡片
- **修改后自动保存**：统一工具窗内的语言、翻译和输入法设置自动保存，切页或关闭前提交尚未保存的修改；语言与翻译设置在下次录音生效
- **保存失败保留草稿**：无法写入配置时留在当前页，显示重试入口，不把未保存的选择当成已保存，也不因关闭窗口丢失草稿
- **刷新不丢选择**：修复资源、模型和麦克风刷新后的选中项显示问题；暂时不可用的已保存引用不会因刷新被清空
- **保留安装维护能力**：安装、修复、卸载、状态查询和权限提示集中在输入法管理中，日常听写无需保持主程序窗口打开

### 隐私与兼容性
- 汇总统计仍只读查询、不读取原文；选中会话后才读取该会话已保存的文字，关闭原文记录后仍可查看此前保存的历史，未保存的原文无法补回
- 统计口径、原文分页和取消读取保持不变，旧请求不会覆盖新选择；定稿字数不代表目标应用成功插入字数，也不用于费用计算
- 保留旧窗口构造和兼容入口，不改变录音、识别服务或输入法登记行为

### 发布内容
- 主程序与语音输入法统一升级为 **v2.3.0**
- 继续提供 Windows x64／ARM64 的 FDD 压缩包，主程序发布包不附带 GPT Image CLI／画图 skill

本版本为 **FDD（Framework-dependent）** 发布，需要预先安装： [**.NET 10 Desktop Runtime**](https://dotnet.microsoft.com/download/dotnet/10.0)

### 使用方式

1. 下载对应架构的 zip 文件
2. 解压到任意目录
3. 运行 `TrueFluentPro.exe`
