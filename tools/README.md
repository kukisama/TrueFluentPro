# tools 目录说明与管理规则

`tools` 存放正式辅助工具、回归测试、素材制作脚本和参考资料。不能整体删除，也不应整体加入 `.gitignore`：部分源码直接参与主程序构建和发布。

## 当前目录布局

- **`回归测试/`**：九个有效回归项目的源码、项目文件、正常测试入口及说明；详见 [回归测试目录说明](回归测试/README.md)。原有 solution 成员关系不变，仅更新四个项目的路径。
- **`待删除/`**：九个旧回归完整目录及两个缓存残留原约 5.11 GiB，加上本次编译验证输出后最终约 6.85 GiB。保留原始源码和全部产物，供用户手动删除；不参与当前测试入口，也不上传 GitHub。
- **正式工具与资料**：`Updater`、`VoiceImeNative`、`GptImageCli`、素材脚本、`reference` 和示例图仍在原位置，没有移动。

迁移时复制 63 个保留文件，逐文件 SHA256 校验一致；未复制 `bin`、`obj`、`artifacts`、两个旧安装基线恢复脚本及旧验收记录到活动区。九个项目编译通过后，新生成的 18 个 `bin/obj` 目录也移至 `待删除/本次迁移验证`；活动区最终为 64 个源码和说明文件、约 1.21 MiB。以后需要运行时重新编译对应项目。

## 本地体积与 GitHub 上传不是一回事

2026-11-08 只读核对结果：

| 项目 | 当前数量／大小 |
|---|---:|
| 本地 `tools` 全部文件 | 6.06 GiB（6,505,822,924 字节） |
| Git 已跟踪文件 | 201 个，3.47 MiB（3,637,669 字节） |
| 已跟踪的 `bin`／`obj`／`artifacts` 等生成物 | 0 个 |
| 未被忽略、尚未跟踪的文件 | 0 个 |

以上是新增本说明、迁移目录前的工作区快照，不代表 Git 历史大小或网络传输量。体积主要增长在本地编译输出和多轮测试程序副本，而不是上传的源码。原回归目录中的大文件现已集中到 `待删除`，仅移动不会释放磁盘空间。

根 `.gitignore` 的 `bin/`、`obj/`、`out/`、`artifacts/` 会匹配各层同名目录，`**/target/` 覆盖 Rust 编译输出；`*.log`、`*.tmp` 等也已忽略。当前核对的默认产物路径均被覆盖，无需屏蔽整个 `tools`。

规则依据：[Git 官方 gitignore 文档](https://git-scm.com/docs/gitignore)明确说明，无开头或中间斜杠的目录规则可匹配下层各级目录，且忽略规则不影响已跟踪文件；[git check-ignore 文档](https://git-scm.com/docs/git-check-ignore)说明 `-v` 可显示命中的规则及来源。本次已用实际路径核对。

## 单文件接口探测脚本

`test-response-oddsize.ps1` 用于探测非标准尺寸图片的 Responses 图片生成行为。它会读取用户 AppData 配置中的凭据，上传选定图片至真实服务的 `/v1/files`，随后调用 `/responses`；不是离线测试，也不是 `/v1/images/edits` 测试。

只有明确需要真实接口探测、确认图片可上传及相关费用后才运行。配置、密钥、请求中的用户图片与服务响应不能随意提交到 GitHub。

## 后续目录管理

- **回归集中、正式工具不动**：新增回归源码放 `回归测试`；保持正式工具构建和发布路径，不让活动项目依赖 `待删除`。
- **源码进 Git**：保留项目文件、源码、入口脚本、简短使用说明、必要资源和第三方许可。新工具应说明用途、是否调用真实服务、输出位置和构建依赖。
- **产物走忽略目录**：编译输出用工具内部 `bin`／`obj`；测试结果用工具内部或仓库根 `artifacts`。当前 CLI 默认发布目录在 `bin` 下，已被覆盖；自定义输出路径需另行核对。
- **避免上传本地数据**：不提交实际用户配置、凭据、队列数据库、原文、批量图片或临时请求／响应。确需保留的测试基准样本须明确用途并检查脱敏。
- **有选择地清历史副本**：优先清理重复的测试程序副本和编译输出；保留最近有效验收及仍在追查问题的必要失败证据，不设自动删除任务。
- **检查 Git，而不是只看资源管理器**：提交前检查 `git status`、实际暂存文件及 `git check-ignore`。忽略规则不会自动停止跟踪已提交的文件；本次没有发现已跟踪生成物，不需要取消跟踪现有工具源码。

本次已复制保留源码并移动旧目录，没有实际删除文件。项目根 `bin/Debug` 仍被当前输入法登记路径引用，不属于本次可直接删除范围。
