# 宋人书斋·原稿资产制作

新主题独立使用 `Assets/Appearance/InkStudy`，不覆盖旧 `SongStudy`。

## 来源

`design/宋人书斋原稿资产_20261104` 中的三张 2560×1440、high 源图：

- `book-spread.png`：AI 任务 191，空白双页书册。
- `controls-atlas.png`：任务 192，普通／选中书签、朱印、备用细金面板框。
- `ornaments-atlas.png`：任务 193，竹枝、山水、书法标题与流苏。

## 制作

Windows PowerShell 7 中从根目录执行 `tools/InkStudyAssets/Export-Assets.ps1`。默认拒绝覆盖；明确重制使用 `-Overwrite`。也可显式指定输入／输出目录。

先复用公共工具导出十五书册切片与八个组件，再按组件实际金线、朱砂、墨迹确定裁切边界，保留安全边。单纯 alpha 裁切无法排除本批生成图的浅白衬底，因此还要做这个精裁步骤。标题去除浅灰衬底，印面保持实色朱砂；只处理本轮输出，不改源图或清理其他目录。

运行时共 23 张 PNG。其中资产板左下格在本主题是“实时翻译”书法标题，最终名为 `title-calligraphy.png`，不使用公共工具的临时格名 `bamboo-right.png`。

## 使用边界

- 书册用 5×3 独立切片保护书角和书脊，内容分区与书页一致。
- 动态文本、身份、时间、语言和设备值仍由真实 UI 渲染。
- 导航与朱印模板的透明命中面不等于视觉底板；不能为了去重背景而删除点击区域。
- `panel-frame.png` 保留为备用资产；当前洞察区采用干净的真实描边，不让装饰图盖住结果文字。
- 图像不承载业务动作，不含真实配置、账户或密钥。
