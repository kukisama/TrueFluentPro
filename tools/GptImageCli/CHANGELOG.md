# GPT-Image CLI 版本记录

程序当前版本以 `gpt-image --help` 为准；以下为固定的历史版本记录，不作为程序版本配置。

## 1.0.2 — 2026-10-02

### 本次新增
- 程序显式定义版本，主帮助和 `queue/submit --help` 从程序版本元数据获取版本号，不在帮助文案重复维护。
- 成功正常输出图片；最终失败在原图片目录输出同名 `.txt`，以简洁 JSON 保存任务编号、状态、HTTP 状态码、错误码、脱敏上游原文、图片数、模型、模式及请求 ID，不附加分析说明。
- 多图失败沿用 `-01/-02` 序号；本次已成功保存的图片不另写错误占位。TXT 不加入图片结果 `files`，数据库中的任务和每次尝试照常保留。
- 等待重试时不写错误 TXT；本次执行结果不明时标记 `unknown`。同步调用同样输出失败 TXT，但不入库、任务编号为 null。
- TXT 默认不覆盖已有文件，显式 `--overwrite` 才允许覆盖；写日志失败不覆盖已落库的任务错误。活动任务同时预留图片及对应 TXT 路径。
- Debug / Release 发行包包含本版本记录，并由帮助界面提示位置。

### 当前能力
- `images` 文生图、`edit` 单图/多图编辑和蒙版、`responses` 图片工具调用；支持 PNG、JPEG、WebP 输出及尺寸、质量、数量等参数，远端支持范围见 CAPABILITIES.md。
- 异步持久队列、独立后台执行器、按模型分组的并发/RPM 限制与 HTTP 429 冷却重试；支持查询、暂停、恢复、取消和清除未执行任务。
- SQLite 保存任务与尝试诊断，DPAPI 保护参数/连接快照；保留脱敏上游错误、请求 ID、白名单响应头、耗时及重试依据。
- 支持节点名称/ID 选择、环境变量和显式连接参数；支持文本或 JSON 输出及 Windows x64 Native AOT 独立交付。

### 边界
- 旧失败历史和强制中断后的恢复不自动补写 TXT；无法解密参数或输出不可写时，以数据库记录为准。
- 成功不会删除以前的 TXT；取消不删除历史或文件；结果不明不自动重新生图。
- 错误原文沿用安全脱敏，不等于完整 HTTP 响应正文；具体字段、限制和实测范围见 README.md / CAPABILITIES.md。
