# 项目图片与图标资源替换

仅用于明确要求接入项目的图标、Logo、favicon、启动画面或程序内图片；普通生图无需此流程。

## 取得母版

- 用户指定的现有图片可直接作为母版；本轮生成图须先满足[主 skill](../SKILL.md)的保存成功判据，再从 `job.result.files` 选择，不能使用计划输出路径或旧图替代。
- 默认查询原任务；后续替换确实需要等待时用[查询与等待示例](./examples.md#查询与必要等待)。失败、结果不明或超时未确认成功时暂停替换，保留编号，不重提。
- 生成尺寸与平台资源槽位不同；成功保存后再按目标尺寸裁切或转换。

## 定位与替换

1. 确定目标应用及运行入口；从清单、构建配置和代码引用反查资源，按需查[平台入口](./platform-icon-entrypoints.md)。
2. “所有对应资源”仅指该应用同一品牌职责的真实入口，不含截图、测试夹具、设计稿、第三方素材或业务图片。
3. 记录实际存在的入口，不凭目录名补造路径或配置键：

| 显示位置 | 配置 / 代码引用 | 源资产 | 现有生成器 / 生成资产 | 目标产物 |
| --- | --- | --- | --- | --- |
| 实际入口 | 文件及位置 | 实际路径 | 按项目填写 | 本次目标平台 |

4. 核对 favicon、页面/标题栏/关于页、启动页、窗口/EXE、安装包/快捷方式、移动启动器中实际存在的项；不只替换 `dist/target/bin`。
5. 文件名不变时优先只换资产；路径变化才改引用。保留已有统一品牌来源和无关未提交改动。
6. 四宫格严格等分裁切：1024×1024 左下为 `(0,512,512,512)`。保持比例、安全边距和抗锯齿，不拉伸或仅改扩展名。
7. ICO/ICNS/adaptive icon 优先复用项目生成器，仅保留目标平台引用的输出。二进制用图像工具写入，读回必要尺寸、alpha 或哈希。

## 最小验证与交付

- 检查受影响引用与源资产；Web 核对构建副本及实际加载，原生核对重建 EXE/bundle/APK 的实际图标，不以源文件代替产物。
- 复用现有真实 UI 验证和目标平台构建，不因纯图片替换跑全量测试；检查 `diff --check` 及无关生成文件。
- 说明已保存、已替换、已验证的范围与未构建平台；不把入队或保存成功称为资源替换完成。
