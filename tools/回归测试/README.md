# 回归测试

这里只保留继续有效的回归源码、项目文件、正常入口脚本和使用说明。编译输出、临时数据库和测试报告仍放各项目的 `bin`／`obj`／`artifacts`，由现有 Git 忽略规则覆盖。

## 项目清单

| 项目 | 检查范围 | 当前 solution 成员 |
|---|---|---|
| `ConfigurationSaveRegression` | 配置合并、并发持有者、备份和失败重试 | 否 |
| `EndpointCapabilityRegression` | 终结点模型能力恢复与序列化 | 是 |
| `GptImageCli.Tests` | 正式 CLI 与队列的离线回归 | 是 |
| `TranscriptChatRegression` | 字幕问答、听写、主题和窗口相关专项 | 是 |
| `VoiceImeLanguageRegression` | 翻译适配器、时序、回环协议和配置保存 | 否 |
| `VoiceImeRegression` | 输入法协议、共享会话、用量、生命周期和部署保护 | 是 |
| `VoiceImeUiHostRegression` | UI Host IPC、窗口生命周期和内容包隔离 | 否 |
| `VoiceImeUiRegression` | 生产 DLL 的设置、用量、语言窗口验收 | 否 |
| `VoiceImeUsageReport.Tests` | SQLite 报表、只读、隐私和原文分页 | 否 |

构建或运行路径统一为 `tools/回归测试/<项目名>/<项目名>.csproj`。涉及仓库资源的入口从仓库根运行，具体参数和边界见各项目 README 或入口源码。

## 使用边界

- 按实际改动选择对应专项，不要求每次运行全套。
- 部分项目引用主程序，编译可触发其后置构建；另一些项目依赖根 `bin/Debug/net10.0` 的现有生产 DLL。先确认生产产物与待验源码一致，不用旧 DLL 验新功能。
- 本次九个项目逐一编译通过，仅运行迁移后的离线 CLI 帮助入口；生产 DLL 摘要未变。验证生成的 `bin/obj` 已移入待删除区，本目录最终只含源码和说明，需要运行时再编译。
- `VoiceImeRegression` 的 Release 验证、真实系统登记入口不是普通离线测试，不能为确认目录路径而运行。
- 历史恢复脚本依赖旧安装基线，未放入当前活动区。不要把旧恢复方案用于当前系统。

## 待删除区

原始九个目录及两个缓存残留已移动到 `../待删除`，不再由 solution 或当前入口引用。保留文件在复制时已逐项核对 SHA256，路径修正只发生在本目录内。

本次验证生成的 18 个 `bin/obj` 目录放在 `../待删除/本次迁移验证`；整个待删除区最终约 6.85 GiB。

用户可在确认不需要旧报告、截图、安装基线和运行副本后手动删除 `tools/待删除`。删除不会减少当前活动回归源码，但历史证据链接会失效；本次没有删除任何文件。
