凭据布局改版方案 · 高清演示

目标：把「一行说明文字 + 一行输入框」压缩成单行（标签 / 输入框 / 复制按钮），说明改为悬停标签时的气泡提示，并按厂商差异化。下面给出 3 个备选布局。

共同点：所有方案都把字段说明从「占一整行的灰字」改成 悬停标签即弹出的气泡提示，不同厂商提示内容不同（例如百度可只填大模型 ApiKey 或通用 SecretKey 二选一）。这样每个字段从约 3 行高 降到 1 行高，整体高度大幅缩短。把鼠标移到下面演示里的字段名（如 AppId、API Key）上即可看到提示。
A

方案 A · 经典三段行（推荐）

标签 + 输入框 + 复制
🎙️
百度实时语音
02 终结点
识别凭据（实时语音转写） ⓘ
AppId 百度语音应用的 AppId（纯数字）。在百度智能云「语音技术 → 应用列表」中创建应用后获得。
API Key 识别用 API Key（AppKey）。与 AppId 在同一应用详情页获取，用于实时语音识别鉴权。
机器翻译凭据（可选） ⓘ
翻译厂商
翻译 AppId 百度翻译开放平台的 AppId。留空则复用上方识别 AppId。
翻译 ApiKey 可选 百度大模型翻译 ApiKey（优先使用）。与下方通用 SecretKey 二选一即可，无需都填。
翻译 SecretKey 可选 通用翻译 SecretKey（回退方案）。若已填大模型 ApiKey 则可留空。
B

方案 B · 前缀标签内嵌

标签嵌在输入框左侧
🎙️
讯飞实时语音
01 终结点
识别凭据（实时语音转写）
AppId 讯飞开放平台语音应用的 AppId。在控制台「我的应用」中查看。
ApiKey 讯飞实时语音转写（RTASR）的 ApiKey，用于鉴权。
ApiSecret 可选 视服务类型可选的 ApiSecret；部分服务无需填写。
机器翻译凭据（可选）
翻译厂商
翻译 AppId 讯飞 NiuTrans AppId；留空则复用识别 AppId。
翻译 ApiKey

方案 C · 紧凑双列网格

两字段并排 · 最省高度
🎙️
百度实时语音
02 终结点
识别凭据
AppId 百度语音应用 AppId（纯数字）。
API Key 识别用 API Key（AppKey）。
机器翻译凭据（可选）
厂商
翻译 AppId 留空则复用识别 AppId。
ApiKey 选 大模型 ApiKey 与 SecretKey 二选一。
SecretKey 选 通用回退；填了 ApiKey 可留空。
选型建议：
· 方案 A（推荐）：与现有控件改动最小，TextBox 直接横排即可；可读性最好，标签对齐整齐，适配 Avalonia 现有 ToolTip.Tip。
· 方案 B：最现代美观，但前缀标签内嵌需要自定义控件模板，Avalonia 实现成本略高。
· 方案 C：高度最省（两字段并排），但窄面板下可能略挤；适合字段多的厂商（如百度 4 个翻译字段）。
