## 可变书脊覆盖规则（2026-11-05）

下表保留原稿测定值供对照；当前拖拽版使用以下横向联动规则，不再将固定中缝坐标视为所有状态的约束：

- 书内纸面范围 x=343–2521，总宽 2178。默认书脊中心 x=1378，左页占约 47.5%；左页范围允许 25%–55%。外侧书缘、封皮、导航位置固定。
- 同一个 `--spine-x` 驱动左右纸面宽度、内阴影、装订线、上下折口、标题分隔线，以及两页正文的坐标和宽度。左正文 x=406，右边距中缝 24；右正文 x=书脊+47，右端固定 x=2463。
- 上下书缘都用五个嵌套 SVG 视口裁取原有 PNG：外角固定、两侧平直段伸缩、128px 中央折口随动。顶部外角各保留 160px，底部右端保留 360px，避免拉伸砚台与边饰。原始 PNG 不覆盖。
- 上书缘最后 14px、下书缘最初 14px 渐变融入连续纸面；装订线覆盖 y=106–1366，和书缘渐变段交叠。横／纵向 alpha 蒙版取交集，装订线两侧及两端柔和衔接，不用实色遮条掩盖错缝。
- 书脊拖柄与纸面分离：外观窄、屏幕命中宽度至少 36px。整条拖柄取消通用红色矩形焦点框；键盘操作时只在中间把手显示青黛轮廓。提示文字不参与布局或鼠标命中。
- 左页变窄时先隐藏副题和波形，正文保持字号、自然换行；山水由所属正文面裁切。右页工具栏自然换行，洞察正文最大行宽 1100，表单和固定控制带跟随右页宽度。
- 25%／35%／原比例／50% 用于同一页直接比较；拖动按实际舞台包围盒换算缩放，捕获当前 pointer，释放／取消时收尾，双击与 Enter 复位。每次键盘微调 1%、Shift 快调 5%；Home／End 到达边界。
- 仅在本地 HTML 原型启用，不迁移 C#／XAML、不改桌面应用主题或字体。其他业务书签仍保持原来的演示边界，本轮不实现五个完整业务页面。

## 字体与色层级
- 书法标题：本机 `STXingkai`（华文行楷），68px，黑墨；不是原稿字形的精确字体识别。
- 书签／品牌／页内标题：`STKaiti` / `KaiTi`，32–44px，辅助文字 23px。
- 对话中文：`Microsoft YaHei UI` / `Microsoft YaHei`，36px；英文：`Times New Roman`，32px；历史／洞察正文：楷体 26px，洞察行高 1.3；表单：21px。
- 对话字号设置的 16 / 20 / 24 是逻辑阅读档位，映射画布正文 36 / 42 / 48px；不是把 16px 当原稿视觉字号。
- 墨色 `#111823`，辅助墨 `#59616b`，青瓷 `#4d7979`，朱砂 `#be3f31`；不以红蓝作音源人物身份映射。
- 层序：案面竹枝 → 侧栏封皮 → 书册封皮／纸页 → 内容透明面 → 山水边饰 → DOM 正文控件 → 中缝及外书缘 → 浮动书签／朱印。

## 素材原则
- 不复制原稿整页作背景，不保留原稿对话、选择器、按钮文字或其他完整控件。
- 原图裁出：案面纸纹、页内纸纹、书缘窄条、中缝、山水、竹枝、书签边框、朱印外框、墨砚。书签内部与朱印文字区用原图同类纸纹／朱砂纹理补成空白；竹枝与墨砚以暖纸去底后的 alpha 组件嵌入。
- 原图 2560×1440，不降采样；组件使用原像素比例。CSS/SVG 绘制控件与线性图标，没有重复 UI 光栅内容。
- Windows 商业字体仅以 `local()` 引用，不复制分发字体文件。其他设备字形可能回退。
- 本轮不生图；因此没有生成模型、生成质量参数或任务编号。

## 内容与交互契约
- 默认两段保留原句与英译，均为麦克风来源；长对话额外示范系统音频和未知源，未知只标音频输入，不猜混合。实时音源不等于文件转写分人。
- 默认双语显示与高亮一致。所有原译文可选择；不提供两人音量、静音、朗读、收藏、卡片复制、交换语言或假章。
- 右页两个独立 DOM panel，切换只 hidden、不销毁。保存各自滚动位置、展开条目、提问草稿与结果。
- 默认会议报告七节 42 条正文，约 51 行；按约 18–26 行的可读一屏目标布置，其余独立滚动。实际可见行数、字体回退与展开设置后的遮挡需共享页验收，不以 CSS 数字冒充测量。
- 历史 30 条完整双语 fixture，最近 15／全部切换不重建 DOM；details 展开附近语句，清空需确认，可恢复，不触碰洞察或会话。
- 洞察预设五类、自定义提问实际生成多节示例；停止生成取消 timer 并递增 token，恢复原结果，清除清输入但不取消自动模式或历史。
- 自动分析保存 enabled／mode／interval／prompt／buffer。本地 timer 下限 10 秒，默认 30 秒，启动立即一次；新数据合并触发，不增加历史。停止自动仅取消调度，不混同当前生成或翻译停止。
- 配置为内存事务：打开 clone 草稿，保存校验并提交，取消丢弃。提示词模板保留 {history}/{question}；模型仅占位。生成结果末尾可查看本次配置应用。
- 设置默认收起，控件已配置状态不表示云连通。麦克风／系统回环、识别／录制来源、语言与资源会话中锁定；字号、字幕保持可用。
- 开始 → 可取消连接 → 运行 → 停止（均本地）；底栏不属于设置表单或滚动内容。墨砚低层且右退，主按钮父层高于书缘，保留完整点击区域。
- 页面内浮动洞察同步当前结果，不生成第二次；首次锚定右页阅读区，宽高根据实际视口适配，关闭／置顶／字号／标题拖动，屏内夹紧在独立控制带上方。字幕预览位于左页，不挡右侧主按钮。
- 书签 hover 放大1.045、抬升、轻角度与投影，未选中书签不出现第二份红框；其他业务仅书签 demo，页内说明。
- tabs 左右／Home／End／Tab；预设菜单上下／Home／End／Escape；原生 dialog Escape／取消及焦点回归；减少动效时取消动画但保留状态。
- reset 停生成／自动／连接，恢复初始双语、七节洞察、30条历史、折叠设置、浮窗、字号与主题，无迟到回写。
